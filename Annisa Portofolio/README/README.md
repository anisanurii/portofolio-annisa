# 🌐 Annisa Nur Iksan - Personal Portfolio Website

Ini adalah website portfolio pribadi dari Annisa Nur Iksan, dibangun dengan HTML dan CSS sebagai bagian dari dokumentasi profesional serta showcase skill dan pengalaman.

## ✨ Fitur Utama

- Halaman utama yang menampilkan foto, deskripsi singkat, dan link sosial
- Navigasi antar halaman: Home, Skills, Education, Experience, Contact
- Efek teks mengetik dinamis (CSS-only typing effect)
- Desain responsif yang dapat menyesuaikan di berbagai perangkat
- Link untuk menghubungi lewat Gmail, WhatsApp, dan LinkedIn

## 🛠️ Teknologi yang Digunakan

- HTML5
- CSS3
- Font Awesome (untuk ikon)
- Google Fonts (Poppins)

## 📁 Struktur Halaman

- `index.html` — Beranda dengan deskripsi diri dan link sosial
- `skills.html` — Menampilkan skill teknikal dan soft skill
- `education.html` — Riwayat pendidikan dengan logo kampus
- `experience.html` — Pengalaman kerja, proyek, sertifikasi, dan organisasi
- `contact.html` — Informasi kontak dan media sosial
